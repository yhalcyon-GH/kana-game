# Asset conventions

- **`design/`** — source/editable material: original PNGs, reference sheets, source PDFs/scripts, and (for audio) the as-generated master clips. Not optimized for delivery; not necessarily what the app actually loads at runtime.
- **`public/`** — the exact, optimized files the app serves in production (Vite copies `public/` verbatim into the build). Images here are converted to WebP; audio here is what `useTTS`'s `speak()` actually plays.

When adding a new asset, put the source under `design/` in the folder for its use, then place the converted/served copy under the matching `public/` path referenced from app code (never hardcode asset paths inside a component — reference them from the relevant `src/data/*.ts` definition, e.g. `src/data/introGuide.ts`/`introGuideContent.ts` for the Tamamizu Guide).

Current `design/` layout by purpose:

- `design/images/tamamizu/` — Tamamizu (the mascot) reference art and individual posed/expression images. `public/mascot/*.webp` (answer-feedback mood crops, see `components/Mascot.tsx`) and `public/guide/tamamizu-sitting.webp` (the Tamamizu Guide's pose, see `components/IntroGuide.tsx`) are both derived from files here.
- `design/images/guide/` — source material for the Tamamizu Guide's slide illustrations (currently `文字.pdf`, 3 pages). `public/guide/slide-*.webp` are rendered/converted from it.
- `design/images/word-illustrations/` — per-word vocabulary illustrations; `public/word-icons/*.webp` are the served crops.
- `design/images/similar-letters/` — source explanation images comparing look-alike katakana pairs/groups (シ・ツ, ソ・ン), shown in Learn and Tracing for the Similar Letters lesson (see `data/similarLetterExplanations.ts`). `public/similar-letters/*.webp` are the served copies.
- `design/audio/guide/` — source narration clips for the Tamamizu Guide (as generated by `scripts/generateGuideAudio.ts`). `public/audio/guide/*.wav` are the exact same files, served at runtime.
- `design/audio/characters*/`, `design/audio/words/`, `design/audio/character-voice/` — source narration/reaction audio for characters, words, and Tamamizu's in-game feedback voice; see `scripts/generateAudioElevenLabs.ts` and `scripts/elevenLabsClient.ts`.

Keep new assets (Tamamizu images, Guide images/slides, narration, future sound effects, ...) inside the folder matching their purpose above rather than starting a new ad-hoc location — add a new purpose-named subfolder here if something genuinely doesn't fit yet.
