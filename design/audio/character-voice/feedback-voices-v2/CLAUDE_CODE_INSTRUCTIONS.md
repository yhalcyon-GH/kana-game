# たまみず音声・Claude Code用指示

`audio` フォルダ内のMP3をアプリの音声アセット置き場へコピーしてください。

## 通常正解
- `correct_seikai.mp3` — 正解！
- `correct_kakkoii.mp3` — かっこいい！

上記からランダムに1つ。同じ音声の連続再生は避ける。

## 通常不正解
- `wrong_donmai.mp3` — ドンマイ！
- `wrong_oshii.mp3` — 惜しい！
- `wrong_ganbatte.mp3` — 頑張って！
- `wrong_zannen.mp3` — 残念！

上記からランダムに1つ。同じ音声の連続再生は避ける。
不正解時は連続正解数を0に戻す。

## 連続正解
節目では通常正解音声を再生せず、専用音声だけを再生する。

- 5連続：`streak_5_sugoi.mp3` — すごい！
- 8連続：`streak_8_kanpeki.mp3` — 完璧！
- 10連続：`streak_10_saikou.mp3` — 最高！（15問モードのみ）

## 共通ルール
1. 1回答につき音声は1つだけ再生する。
2. 連続正解の専用音声を通常正解音声より優先する。
3. 音声を重ねて再生しない。
4. 前の音声が再生中なら停止してから次の音声を再生する。
