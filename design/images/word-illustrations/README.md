# Word icon provenance

Backups/sources for the vocabulary illustrations shipped at `public/word-icons/<word-id>.webp`. Kept for provenance only — nothing here is read by the app at runtime (see `CLAUDE.md`'s `design/` note).

- **`chatgpt-batch-2026-08-19/`** — the batch used to (re)source illustrations for every word with an `image` field as of 2026-08-19, sourced via ChatGPT directly from finished per-word images (not cropped reference sheets). `images/` (277 files) is the full-catalog replacement pass merged with later same-day additions/individual replacements (originally kept as separate `main/`+`extras/` folders; merged once flat since it's all one batch in practice). `vocab-mapping.csv` is the word-id ↔ filename mapping used to apply the original full-catalog pass. This batch superseded 95%+ of every earlier batch below. Note: `sokuon-ikki` was briefly replaced by an individual same-day resubmission, then reverted back to this batch's original — `images/sokuon-ikki.png` is that original.
- **`still-live-legacy/`** — the handful of pre-2026-08-19 icons that are still actually live because `chatgpt-batch-2026-08-19` didn't happen to cover them: `wa-mizu-wo-nomu` (`youon-ka-gyuuniku` was here too, until it got its own `extras/` replacement above — its old copy moved to Desktop/Dust).

`pending-review/` (gitignored, created on demand) is where `scripts/generateWordIcons.mjs` writes a fresh batch for review before it gets a permanent named folder here.

## Superseded batches (moved to Desktop/Dust, 2026-08-19)

The pre-2026-08-19 generation history — `hiragana/` (89 original hand-sourced/paid icons), `katakana-gemini-review/` (109 Gemini `gemini-2.5-flash-image` icons for katakana/そくおん/ちょうおん/拗音, plus the `review.html` gallery used to review the batch), `katakana-chatgpt/` (11 ChatGPT replacements for the first-pass Gemini katakana icons), `youon-chatgpt/` (all 60 拗音 icons, cropped from six ChatGPT reference sheets), `chouon-chatgpt/` (the final 7 ちょうおん icons completing coverage for all 261 words at the time), `chatgpt-round-2/` (a second ChatGPT pass re-doing 51 words — also where a real crop-boundary pipeline bug involving transparent PNG backgrounds got found and fixed, see the "Re-crop 55 word icons" commit), and `chatgpt-round-3/` (a third pass) — is no longer in this repo. See `Desktop/Dust/superseded-word-illustration-batches/` if it's still there, or git history before 2026-08-19 otherwise.
