# 2026-08-15 新カテゴリー5種の実装セッション

`docs/curriculum-extensibility.md`で決定した設計に基づき、カタカナ・促音・長音・拗音・特殊音の5カテゴリーをすべて実装した夜間セッションの記録。各カテゴリーは背景で動くエージェントに実装させ、完了ごとに本セッション側で独立に再検証(build/lint/test再実行、内容の抜き取り確認)してから次に進んだ。

## ブランチ構成

`main`から順に連なる形で、各カテゴリーが1つ前のブランチから分岐:

```
main
 └─ feature/katakana
     └─ feature/sokuon
         └─ feature/chouon
             └─ feature/youon
                 └─ feature/tokushuon
```

5つとも**push済み・未マージ**。この順番(前のブランチが依存関係にあるため)でレビュー・マージするのが安全。

## 促音レビュー中に発見・修正した実バグ

促音実装のレビュー中に、`getCumulativeCharacterIds`(distractor選択肢の元になる関数)のロジックに実際の不具合を発見しました。

**問題**: カテゴリー間の依存関係を「`CATEGORIES`配列での宣言順」から推測していたため、カタカナの各行が(依存する必要のない)ひらがな全71文字を巻き込んでしまっていました。実際に検証: `getCumulativeCharacterIds('katakana-a-row')`が`'a'`(ひらがな)を含んでいることを確認。これはカタカナのKana Quizで「アの正解選択肢の中にひらがなのあが紛れ込む」ような不具合になり得ました。

**修正**: `ScriptCategory`に明示的な`dependsOnCategoryIds`フィールドを追加し、配列順からの推測をやめました。カタカナは依存なし(独立したスクリプト)、促音・長音は`[hiragana, katakana]`に依存(単語が両スクリプトの音を混ぜて使うため)、特殊音は`[katakana, sokuon]`に依存、という形で明示。回帰テストも追加済みです(`curriculum.test.ts`)。この修正は促音ブランチの一部としてコミットされ、以降の長音・拗音・特殊音ブランチにも正しく引き継がれています。

## 音声・画像について(全カテゴリー共通)

- **音声は指示通り一切生成・組み込みしていません**(全カテゴリー)。
- **単語の挿絵はありません**。`AnchorWord.image`を任意項目にし、`WordImage.tsx`のプレースホルダー(🖼️)で対応しています。
- 一部の文字(拗音のみゅ・りゃ、特殊音のとぅ・どぅ・ヴ単独等)は実際に使われる語彙が乏しく、対応する単語を用意できていません。各カテゴリーのコード内コメントに明記されています。
