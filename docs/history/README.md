# Historical documentation

This directory is an archive of dated session reports, review notes, release-audit evidence, and superseded implementation plans/specs.

Use these files to understand provenance, prior investigations, and why a decision was made. **Do not treat them as current product or architecture authority.** Current user decisions, accepted task specifications, current code/tests, and recent repository evidence outrank historical narrative; see [`../ai-development-loop.md`](../ai-development-loop.md).

Subdirectories:

- `sessions/` — end-of-session reports and rollout notes.
- `design/` — dated design documents whose implementation/status has since evolved.
- `reviews/` — point-in-time review notes.
- `release-audit/` — release audit findings retained as evidence.
- `superpowers/` — old implementation plans/specs retained for provenance.
- `asset-audits/` — dated image/audio asset inventories and audit summaries.
